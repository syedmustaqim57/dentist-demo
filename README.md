# DentoCare

Demo dental clinic website. React + Vite + Tailwind CSS + Lucide React.

## Run locally
```
npm install
npm run dev
```

## Notes
- Images are remote Unsplash URLs, all listed in `src/data.js`. Swap any URL there to change it site-wide.
- If an image fails to load, a soft blue tile appears so the layout never breaks.
- Contact details, testimonials and social links are demo placeholders.
